# Privacy Policy

Last updated: September 5, 2026

FUTTY Bot is a Discord bot that links Roblox accounts to Discord members through Roblox OAuth2.

## Information collected

When a user verifies, FUTTY Bot stores:

- Discord user ID
- Roblox user ID
- Roblox username
- Roblox display name
- Verification date and time

The bot does not store Roblox passwords or OAuth access tokens.

## How information is used

Stored information is used to verify account ownership, assign the configured Discord role, update the Discord nickname, and display linked account information through bot commands.

## Sharing

The bot does not sell or share stored information with third parties. Information may be visible to members of a Discord server through the bot's verification features and `/whois` command.

## Data removal

A user can request removal of their linked data from the person or organization operating the Discord server where the bot is installed. The request should include the Discord account and Roblox account involved.

## Changes

This policy may be updated when the bot's data practices change. The latest version is available in this repository.

## Contact

For privacy questions or data removal requests, contact the administrator of the Discord server using FUTTY Bot.
