# FUTTY Bot

FUTTY Bot links Roblox accounts to Discord members through Roblox OAuth2.

## What the bot does

- Lets a Discord member verify a Roblox account.
- Assigns a verified role after successful verification.
- Updates the member's Discord nickname.
- Shows linked Roblox account information with `/whois`.
- Lets server administrators configure the verified role, nickname format, verification panel, and settings administrators.

## Data stored

The bot stores the Discord user ID, Roblox user ID, Roblox username, Roblox display name, and verification time. OAuth access tokens are used only while completing sign-in and are not stored.
